# Fikrat Aliyev Portfolio Site

Static portfolio website.

## Entry point
Open `index.html` in a browser.

## Project structure
- `index.html` — main page, styles and scripts
- image/SVG assets — project and client visuals used by the page

## Notes for Codex
- Preserve the current visual design and project content unless explicitly requested otherwise.
- Keep asset paths relative to `index.html`.
- File names are case-sensitive when deployed to Linux/GitHub Pages.
- The project currently uses external CDN resources referenced from `index.html`.
